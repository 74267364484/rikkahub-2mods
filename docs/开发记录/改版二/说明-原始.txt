   - 没授权 -> 弹系统对话框「需要「所有文件访问权限」」[去授权] [稍后]
     -> 点「去授权」跳系统设置, 三级回退:
        APP 专属授权页 -> 所有文件访问列表页 -> 应用详情页 -> 文字指引 Toast
   - 从设置页回到 APP 会提示结果: "✓ 已获得..." 或 "仍未获得...(开关可能没打开)"

改了什么:
 1. 提示词: 原来 APP 告诉模型"工作区是 sandboxed proot rootfs、路径必须在 Rootfs 内",
    所以模型会回答"我看不到你的设备"。现在提示词/工具描述改成明确告知:
    /sdcard (= /storage/emulated/0) 和 /storage 是【手机真实存储】(相册/Download/Documents/
    Pictures/Music/Android/media...), 可以直接读写, 隐藏文件也可见, 不许再说看不到设备文件。
 2. 工作台文件区默认落在手机存储: /storage/emulated/0/RikkaHub/workspaces/<工作区ID>/
    -> APP 的"文件"页看到的就是手机上真实目录(隐藏文件也列)
    -> AI 的 /workspace 也是这个真实目录
 ★ 长按桌面图标有两个快捷方式:
   - 「手机存储权限」-> 直接打开系统「所有文件访问权限」页(任何时候都能手动授权)
   - 「设置工作台目录」-> 系统目录选择器, 选完自动写入配置
   (Android 对「所有文件访问权限」没有弹窗式申请, 只能跳系统设置页; APP 启动时也会自动跳一次)

 3. 换目录(推荐用快捷方式): 长按桌面「RikkaHub Mod」图标 -> 选「设置工作台目录」
    -> 系统目录选择器里挑一个文件夹 -> 提示"工作台目录已设为: xxx" 即生效
    (看不到这个快捷方式的话, 重启一次桌面/等几秒; 装完第一次可能要等系统刷新快捷方式)
    手动方式(等效): 建文件 /storage/emulated/0/RikkaHub/workspace_base.txt, 内容写绝对路径
      /storage/emulated/0                -> 整个内部存储当工作台(文件页可浏览全机存储)
      /storage/emulated/0/Download       -> 就用下载目录
      /storage/emulated/0/my/{root}      -> 每个工作区一个子目录
    即时生效, 不用重启。
 4. proot 挂载: /storage/emulated/0 -> /sdcard, /storage -> /storage (shell 和 AI 工具都能用)
 5. 写 /sdcard、/storage 不再弹审批; 隐藏文件本来就显示(只过滤 proot 的 .l2s. 临时文件)

验证: 新开对话, 让它 "ls -a /sdcard/Download" 或 "读一下 /sdcard/Download 里最新的文件"
      -> 现在它应该直接执行, 而不是说看不到你的设备。
